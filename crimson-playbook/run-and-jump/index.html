Run & jump: one controlled trigger

An optional man-pressure changeup after containment and communication are reliable.

Step 1

Set up

Pause at the decision. Ask: “What did the defender do? Where is the space?”

Set it up

5-on-5, full court. Teach one trigger: dribbler turns away with eyes down, and the nearest helper has safe distance to contain.

Three coaching cues

  1. No trigger? Stay with your man.
  2. On “jump,” helper takes the ball; original defender takes the helper’s player.
  3. Others stay matched and protect deep; this is a two-player exchange, not a zone trap.

Run it at practice

6 minutes after base defense is sound • Guided jump/no-jump reps, then short live possessions. Count a failed exchange as a defensive loss even if someone steals the ball.

Optional progression, not the starting defense. Use only if event rules allow full-court pressure and help exchanges. Remove it if it creates fouls or layups.

Walk through the read

All defensive reads

Eyes down • Exchange: 1 turns away near the sideline. X3 calls “jump” and takes 1; X1 rotates to 3. X2, X4 and X5 stay with their players.

Eyes up • Stay home: 1 sees the floor and keeps advancing. A jump would surrender a pass, so every defender remains with the original matchup.
