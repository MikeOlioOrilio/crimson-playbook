Laker: five-lane fast break

Rebound, outlet, fill wide lanes, then read the first defender. Everyone learns every lane.

Step 1

Set up

Pause at the decision. Ask: “What did the defender do? Where is the space?”

Set it up

5 players, 1 ball, full court. Start 5-on-0; add two guided defenders only after spacing is reliable.

Three coaching cues

  1. Secure the rebound before anyone leaks out.
  2. Nearest outlet talks; first available runner takes the rim lane.
  3. No early window? Keep the ball and flow into five-out.

Run it at practice

8 minutes • Groups of five go down and back, then rotate lane jobs. Target 4 of 5 trips with a secure outlet and no lane collisions; add guided defense, then live 5-on-2.

Walk through the read

All defensive reads

5-on-0 • Learn the lanes: No defense in this rehearsal. The rim pass practices timing; it is not an automatic pass in a game.

Rim open: X1 stops 1; X2 stays wide with 2. Pass to 5 before X2 can recover.

Rim covered • Corner: X2 protects the rim with 5. 2 is available wide; pass to feet, then read the closeout.

Both covered • Trailer: X2 takes 5 and X1 shades 2. Reverse to 4 instead of forcing a crowded finish.
